## What Is This?

This is an open-source AI course designed for pupils aged **14–18**, with no assumed knowledge of programming or mathematics. Every concept is introduced *after* you've already played with it — you run the code first, then we explain what just happened.

By the end, you'll have:

- Trained your own machine learning models
- Made predictions on real scientific data
- Built and broken a neural network
- Thought critically about bias and fairness in AI

All notebooks run in **Kaggle Notebooks** — nothing to install, free GPU included.

🌐 **Course landing page:** [ucl.ac.uk/disi/ai-training-course](https://www.ucl.ac.uk/disi/ai-training-course)

## Course Structure

The course follows a simple loop throughout: **Code → Observe → Explain → Improve**

| Module | Title | Topics |
|--------|-------|--------|
| **0** | Welcome to AI | What is ML? How to use Kaggle |
| **1** | Your First AI Model | Train a classifier, features & labels |
| **2** | Making Predictions | Regression, plotting results |
| **3** | Improving a Model | Parameters, overfitting |
| **4** | Exploring a Real Dataset | Data visualisation, summary stats |
| **5** | Splitting Data Properly | Train/test splits, evaluation |
| **6** | Decision Trees | Tree visualisation, depth & overfitting |
| **7** | Random Forests & Boosting | Ensemble methods, model comparison |
| **8** | Build a Tiny Neural Network | PyTorch, layers, loss curves |
| **9** | Breaking the Network | Overfitting in neural networks |
| **10** | Image Classification | CNNs, torchvision |
| **11** | Science Dataset – Classification | Real-world application |
| **12** | Science Dataset – Prediction | Predicting physical quantities |
| **13** | Open Challenge | Choose your own model |
| **14** | Bias in Action | Dataset bias, fairness, resampling |

## Getting Started

Every notebook has an **Open in Kaggle** button at the top. Just click and go.

If you'd like to run things locally:

```bash
git clone https://github.com/UCL/UCL-AICourse.git
cd UCL-AICourse
pip install -r requirements.txt
```

**Core dependencies:** `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `torch`, `torchvision`
